Каждый блок ниже — секция одного markdown-файла. HERON понимает её форму по тому, как она написана, а тема рисует каждую форму своим модулем.

Откройте `content/ru/forms.md` рядом с этой страницей: файл и страница бок о бок — вот и вся инструкция.

## Просто текст {#text}

Секция без списка, таблицы и цитаты — это проза. **Жирный**, *курсив*, [ссылки](/ru/) и `код` работают как обычно.

## Список {#list}

- **Сначала термин.** Жирное начало с точкой делает пару: тема получает термин и текст по отдельности.
- **Любая длина.** В пункте может быть предложение или короткий абзац.
- Обычный пункт без жирного начала тоже можно.

## Тревожные признаки {#warning .alert}

- Класс `.alert` в заголовке превращает список в предупреждение.
- Для того, что нельзя пропустить.

## Шаги {#steps}

1. **Создайте сайт.** Одна команда — и папка готова:

   ```bash
   heron new my-site -y
   ```

2. **[ЧАЩЕ ВСЕГО] Заполните анкету.** Метка в квадратных скобках заглавными буквами отмечает шаг.
3. **Соберите.** Итоговая сборка открывает сайт поисковикам.

## Вопросы {#faq}

### Это настоящая страница?

Да. Каждый блок на ней нарисован стартовой темой из этого файла.

### Её можно удалить?

Удалите `forms.md` в папке каждого языка и уберите `forms` из `nav.main` в `site.yaml`.
