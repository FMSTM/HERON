## 1. Что есть сейчас

Коротко: сколько страниц, какие разделы, на каком языке, какие адреса, сколько трафика, что приносит обращения, какие счётчики.

## 2. Дерево контента

Ключ — путь от `content/<язык>/` без `.md`, одинаковый во всех языках. Адреса второго языка — полем `slug`.

```
content/<основной>/                      тип        <основной>                <второй>
  index.md                               home       /                         /<lang>/
  404.md                                 404        —                         —
  about.md                               about      /about/                   /<lang>/<slug>/
  services/_index.md                     category   /services/                /<lang>/<slug>/
    design.md                        service    /services/design/     /<lang>/<slug>/<slug>/
```

## 3. Типы страниц и секции

| Тип | Страницы | Почему отдельный тип |
|---|---|---|
| `home` | главная | … |

Для `theme.yaml`:

```yaml
types:
  home:
    uses: [intro, "why:list", "how:steps", "faq:faq"]
    jsonld: [WebSite]
links:
  - {field: related, type: service, back: related_from}
```

Секции каждого типа:

| Тип | Якорь | Форма (`kind`) | Что туда | Откуда текст | Обязательна |
|---|---|---|---|---|---|
| `service` | вступление | 2 абзаца | кому помогаем; чем заканчивается | … | да |
| `service` | `{#includes}` | `list`, пары | что входит | … | если есть в источнике |
