# Что HERON уже умеет

Перед тем как написать «нужна доработка движка», найди потребность в этой таблице. Если она здесь есть — делай средствами сайта и темы. Если нет — смотри «Чего нет» внизу: часть вещей отсутствует намеренно.

Ссылки: `20` = `docs/spec/20-data-contract.md`, `21` = `docs/spec/21-engine.md`, `23` = `docs/spec/23-distribution.md`.

## Структура и адреса

| Нужно сайту | Как в HERON | Где описано |
|---|---|---|
| Страница по адресу `/about/` | файл `content/<язык>/about.md` | `20` §2 |
| Раздел с каталогом детей | папка с `_index.md`; дети — файлы рядом; шаблон получает `page.children` | `20` §2, `21` §4 |
| Адрес не совпадает с именем файла | поле `slug` | `20` §2 |
| Разные адреса на разных языках (`/guides/` и `/ru/rukovodstva/`) | одинаковое имя файла, `slug` в файле второго языка | `20` §2 |
| Тип страницы и свой шаблон | `type` в файле или `children_type` в `_index.md` раздела; шаблон `templates/<тип>.html` | `20` §4.2 |
| Одиночная страница со своей раскладкой (`about.md`) | `type: about` в файле, `templates/about.html` в теме | `20` §4.2 |
| Порядок в каталоге и меню | `order` | `20` §4.2 |
| Меню | `nav` в `site.yaml`, ключами; главная — `"/"` | `20` §4.2, §5 |
| Короткое имя в меню и крошках | `nav_title` | `20` §4.2 |
| Хлебные крошки | строятся сами: `page.breadcrumbs` | `21` §6 |
| Черновик, который не собирается | `published: false` (`--drafts` включает) | `20` §4.2 |
| Новая страница с полным SEO-блоком и заготовками секций типа | `heron page <тип> <имя>`; главную и 404 кладут `new`/`init` | `21` §10 |
| Комментарии в файлах сайта по-русски или по-английски | `--notes ru\|en`, `HERON_NOTES`, `build.notes` | `23` §4 |
| Раздел в 100+ страниц | одна страница каталога, без пагинации; группировку делает тема | `21` §4 |

## Языки

| Нужно сайту | Как в HERON | Где описано |
|---|---|---|
| Один язык, два, N | `site.languages`, `site.default_lang` | `20` §3 |
| Основной язык в корне, остальные под `/<lang>/` | так всегда | `20` §3 |
| hreflang, `x-default` | генерируются сами | `20` §3 |
| Переключатель языков, неактивный пункт без перевода | `languages`, `lang`, `page.translations` в шаблоне | `20` §3 |
| Второй язык пишется раньше основного | дев-сборка проходит с предупреждением; прод с пустым основным — `E021` | `20` §3 |
| Ссылка в тексте ведёт на страницу своего языка | писать ключом без префикса: `[x](/guides/x/)` | `20` §2 |
| Название сайта и суффикс `title` по языкам | `site.name_<lang>`, `seo.title_suffix_<lang>` | `20` §5 |
| Адрес, телефон, описание компании по языкам | `contact.address_ru` и т. п. в своих блоках; подстановки и тема берут язык сами | `20` §5 |
| Строки интерфейса темы («Записатися») | `theme/i18n/<lang>.yaml`, в шаблоне `t.<ключ>` | `21` §7 |

## Контент страницы

| Нужно сайту | Как в HERON | Где описано |
|---|---|---|
| Вступление и подзаголовок | текст до первой секции: `lead` и `promise` | `20` §4.3 |
| Блок, который тема ставит в нужное место | секция `## Заголовок {#якорь}` | `20` §4.3 |
| Список, пары «термин — пояснение» | `list` | `20` §4.4 |
| Тревожные признаки | `list` с классом `.alert` → `alert-list` | `20` §4.4 |
| Шаги «как мы работаем», с метками | нумерованный список → `steps` | `20` §4.4 |
| FAQ (и `FAQPage` в разметке) | группы `### Вопрос?` без списков → `faq` | `20` §4.4 |
| Чек-лист документов | три и больше групп `###` со списками → `checklist` | `20` §4.4 |
| «Подходит / не подходит» | две группы `###` со списками → `two-lists` | `20` §4.4 |
| Короткие факты «формат — очно» | строки `ключ \| значение` → `facts` | `20` §4.4 |
| Таблица сравнения | markdown-таблица → `table` | `20` §4.4 |
| Шкала времени | `facts` или нумерованный список с классом `.timeline` | `20` §4.4 |
| Врезка-совет | цитата `>` → `callout` (и `section.callout` у любой секции) | `20` §4.4 |
| Галерея | список картинок с классом `.gallery` | `20` §4.4 |
| Сквозные данные: отзывы, цифры доверия, реквизиты | yaml в `data/`, в шаблоне `data.<имя файла>` | `20` §1 |
| Сырой HTML в markdown | запрещён по умолчанию (`E015`); `build.allow_raw_html: true` | `20` §5 |

## SEO и служебное

| Нужно сайту | Как в HERON | Где описано |
|---|---|---|
| sitemap | генерируется: один файл или индекс по языкам | `21` §9 |
| robots.txt | генерируется; дев — `Disallow: /` | `21` §9 |
| `llms.txt`, полные тексты для нейросетей | генерируются; сведения о сайте — `seo.llms_note` | `21` §9, `20` §5 |
| JSON-LD | типы — `theme.yaml` `types.<тип>.jsonld`; данные — `schema` в `site.yaml` и в странице | `20` §5 |
| Цены в разметке | запрещены, пока `seo.allow_prices: false`; разрешить — `true` | `20` §5 |
| Дата публикации и обновления | `date`, `updated`, `build.updated_from: git` | `20` §4.2, §5 |
| Лента Atom | `seo.feed: <тип>` | `21` §9 |
| Open Graph, картинка по умолчанию по языкам | `og_*` в странице, `seo.og_default_image[_<lang>]` | `20` §4.2, §5 |
| 301 со старых адресов, кириллица и `%D0%…` | `redirect_from` в странице | `20` §2 |
| 410 для архивов, служебных путей, дорвеев | `gone` в `site.yaml`: точные, `/wp/*`, `/?p=*` | `20` §5 |
| Страница 404 на каждом языке | `content/<lang>/404.md` | `20` §2 |
| Счётчики только в проде | `analytics` в `site.yaml`; дев их не выводит | `20` §5 |
| Закрыть дев от индексации | так по умолчанию; прод — `build --env prod` | `21` §10 |
| Образ nginx с сайтом, smoke-проверка | `scripts/site.sh <сайт> image\|smoke\|push` | `23` §5 |

## Чего нет — намеренно или пока

| Чего нет | Почему и что делать |
|---|---|
| Пагинация каталогов | намеренно: один раздел — одна страница. Большие разделы делить на подразделы папками (`21` §4) |
| Поиск по сайту, комментарии, личный кабинет | статический сайт; рантайма нет. Внешний сервис — решение темы |
| Подгрузка контента скриптом | запрещено: числа и текст обязаны быть в HTML (`20` §10) |
| Приём форм | будет отдельный сервис `heron-relay`, **пока не реализован**. Описание формы в `site.yaml` (`forms`, `sinks`) движок проверяет, но POST принимать некому. Сейчас — телефон, почта, мессенджеры, внешняя форма |
| Админка, база данных | намеренно: источник правды — файлы |
| Отложенная публикация по дате | нет: `published` — флаг, `date` — только дата. Публикация = коммит и сборка |
| Яндекс.Метрика в заготовке темы | убрана; ключ `analytics.metrika` принимается, вывести его — дело своей темы |
| Сборка на сервере (`install.sh`, `deploy.sh`) | описана в `22` как целевая схема, скриптов пока нет. Сегодня — образ через `site.sh` |

Если потребности нет ни в одной таблице — это задача на движок. Шаблон оформления — в [`architect.md`](architect.md), раздел «Задача на движок».
