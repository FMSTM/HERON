# static — файлы по точному адресу

Копируется в собранный сайт байт в байт, по тому же пути, без обработки и
без проверок. Это её единственное назначение.

## Сюда

- подтверждение прав вебмастера;
- `.well-known/security.txt`;
- `ads.txt`, проверочные файлы платёжных систем;
- `site.webmanifest`, favicon.

## Не сюда

- **Картинки, видео, документы.** Их дом `media/`: там они получают проверку
  на существование, варианты под размеры экрана и внятную ошибку при опечатке.
  Здесь они не получают ничего — просто лежат.
- **Оформление сайта** — логотип, иконки, шрифты. Это `theme/assets/`.

Положить файл сюда всегда быстрее, чем объявить его в контенте. Именно так
эта папка и зарастает. Пустая `static/` — нормальное состояние сайта.
