Главные команды HERON и где читать подробнее. Документация лежит в репозитории движка и в самом образе — ровно той версии, которой собирается ваш сайт.

## Как запускать команды {#run}

Все команды ниже начинаются с `heron` — это короткое имя для запуска образа HERON в Docker. Как его завести — в разделе «С чего начать» документации. Без короткого имени вместо `heron` пишут полную команду, например:

```bash
docker run --rm -it -p 127.0.0.1:8000:8000 -v "$PWD":/site -w /site --user $(id -u):$(id -g) ghcr.io/fmstm/heron:prod serve .
```

## Главные команды {#commands}

1. **Создать сайт.** Задаст несколько вопросов и создаст папку сайта:

   ```bash
   heron new my-site
   ```

2. **Настроить.** Анкета в браузере — откройте адрес, который она напечатает, вместе с ключом после `#`: название, домены, о ком сайт, публикация, тема. Запускается из папки сайта:

   ```bash
   cd my-site && heron setup .
   ```

3. **Смотреть.** Сайт на `localhost:8000` пересобирается при каждом сохранении файла:

   ```bash
   heron serve .
   ```

4. **Проверить.** Что заполнить и что поправить — без сборки:

   ```bash
   heron check .
   ```

5. **Собрать для проверки.** Версия dev: закрыта от поисковиков, без счётчиков:

   ```bash
   heron build . --env dev
   ```

6. **Собрать рабочую версию.** Версия prod: открыта поисковикам, предупреждения считаются ошибками. Результат — папка `dist/`:

   ```bash
   heron build . --env prod --strict
   ```

## Где читать {#where}

- **В репозитории.** [Гайды по порядку](https://github.com/FMSTM/HERON/tree/beta/docs/guide): понятия, первый сайт, страницы, тема, поиск, публикация.
- **Для ИИ-агентов.** [AGENTS.md](https://github.com/FMSTM/HERON/blob/beta/AGENTS.md): роли, правила и карта документации.
- **В терминале.** Без интернета, той же версии, что и движок:

  ```bash
  heron docs
  ```
