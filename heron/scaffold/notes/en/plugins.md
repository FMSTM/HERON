# plugins — build extensions

Plugins for this site: custom build steps, generators, processors. They are
switched on in `site.yaml` — sitting here is not enough, the engine only takes
what is declared.

## Belongs here

- code for extensions this particular site needs.

## Does not belong here

- **General engine features.** If every site needs it, it belongs in HERON,
  not in one site's folder.

Empty is normal: most sites need no plugins at all.
