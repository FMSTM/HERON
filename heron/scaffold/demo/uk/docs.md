Головні команди HERON і де читати докладніше. Документація лежить у репозиторії рушія та в самому образі - рівно тієї версії, якою збирається ваш сайт.

## Як запускати команди {#run}

Усі команди нижче починаються з `heron` - так вони виглядають, якщо рушій встановлено без Docker. У Docker замість `heron` пишуть повну команду (`-it` - тим, що ставлять запитання, `-p` - перегляду, конфігуратору і студії), наприклад:

```bash
docker run --rm -it -p 127.0.0.1:8000:8000 -v "$PWD:/site" -w /site --user "$(id -u):$(id -g)" ghcr.io/fmstm/heron:prod serve .
```

## Головні команди {#commands}

1. **Створити сайт.** Поставить кілька запитань і створить теку сайту:

   ```bash
   heron new my-site
   ```

2. **Налаштувати.** Конфігуратор у браузері - відкрийте адресу, яку надрукує рушій, разом із ключем після `#`: назва, домени, про кого сайт, публікація, тема. Запускається з теки сайту:

   ```bash
   cd my-site && heron setup .
   ```

3. **Дивитися.** Сайт на `localhost:8000` перезбирається при кожному збереженні файлу:

   ```bash
   heron serve .
   ```

4. **Додати сторінку і розділ.** Сторінка і розділ створюються одразу всіма мовами сайту. Рушій запитає поля з підказками теми: Enter залишає значення в дужках, `?` - докладна довідка. Та сама команда вдруге відкриває сторінку на правку:

   ```bash
   heron page add about . && heron category add services .
   ```

5. **Правити мишею.** Студія в браузері: дерево сторінок, поля з підказками, переклади, довідка теми. Відкрийте адресу повністю, з ключем після `#`:

   ```bash
   heron studio .
   ```

6. **Перевірити.** Що заповнити і що виправити - без збірки:

   ```bash
   heron check .
   ```

7. **Зібрати для перевірки.** Версія dev: закрита від пошукових систем, без лічильників:

   ```bash
   heron build . --env dev
   ```

8. **Зібрати робочу версію.** Версія prod: відкрита пошуковим системам, попередження вважаються помилками. Результат - тека `dist/`:

   ```bash
   heron build . --env prod --strict
   ```

Інструкції для AI-агента лежать у корені сайту: файл `AGENTS.md` і тека `agents/`.

## Де читати {#where}

- **У репозиторії.** [Гайди по порядку](https://github.com/FMSTM/HERON/tree/prod/docs/en/guide): поняття, перший сайт, сторінки, тема, пошук, публікація, своя тема.
- **Для ШІ-агентів.** [AGENTS.md](https://github.com/FMSTM/HERON/blob/prod/AGENTS.md): ролі, правила та мапа документації.
- **У терміналі.** Без інтернету, тієї ж версії, що й рушій:

  ```bash
  heron docs
  ```
