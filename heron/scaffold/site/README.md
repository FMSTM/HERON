# {name}

Сайт на движке [HERON](https://github.com/FMSTM/HERON).

## Три команды

```bash
heron check     # что не так с контентом и конфигом
heron serve     # локальный просмотр с пересборкой
heron build     # собрать в dist/
```

Без установленного движка — через docker:

```bash
./build.sh              # -> dist/
./build.sh --image {slug}:1.0   # -> образ nginx с сайтом внутри
```

## Что где лежит

| Папка | Что внутри |
|---|---|
| `content/<язык>/` | страницы в markdown. Путь файла = адрес страницы |
| `data/` | справочники в yaml, доступны шаблонам как `data.<имя>` |
| `img/` | картинки-мастера 1:1, движок сам режет варианты |
| `static/` | favicon и прочее, копируется как есть |
| `theme/` | шаблоны, стили, строки интерфейса |
| `site.yaml` | домен, языки, тема, меню, версия движка |
