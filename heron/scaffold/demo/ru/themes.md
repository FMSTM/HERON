Тема решает, как выглядит сайт. Тексты страниц от неё не зависят: сменили тему - страницы остались, поменялся вид.

## Как сменить тему {#change}

1. **В конфигураторе.** `heron setup .` - группа «Тема»: выберите тему из каталога, вставьте ссылку на архив или загрузите свой.
2. **Командой.** По имени из каталога, по ссылке или архивом:

   ```bash
   heron theme list && heron theme get ИМЯ .
   ```

3. **Проверьте.** `heron serve .` - сайт в новой теме на `localhost:8000`.

## Что приезжает с темой {#what}

- **Вид.** Шаблоны, стили и шрифты - в папку `theme/`.
- **Демонстрационные страницы.** Образец подачи под тематику темы: какие страницы нужны, какие блоки на них. Они кладутся только туда, где страницы ещё нет: ваши файлы не перезаписываются. Замените тексты своими, а лишние страницы удалите во всех папках языков и уберите из меню.
- **Справка темы.** Всё, что тема умеет: каждый блок с подсказкой, живым примером и его markdown рядом, виды разделов. В просмотре - страница `/_heron/theme/`, в студии - вкладка «Справка темы», в терминале - `heron docs theme-ref .`.
- **Подсказки к полям.** `heron page add` и студия спрашивают поля страницы с подсказками темы, `?` открывает подробную справку.
- **Прежняя тема.** Не удаляется: она уезжает в `.heron-cache/setup/`.

## Своя тема {#own}

Белая тема - основа для своей: поменяйте цвета в начале `theme/assets/site.css`, расставьте блоки в `theme/templates/`. Тема описывает себя в `theme.yaml`: типы страниц, поля каждого блока, виды разделов и подсказки для того, кто будет вести сайт. Её демо обязано показать каждый тип, блок и вид - проверка `heron check . --theme`. Упаковать тему вместе с демо, чтобы поставить на другой сайт: `heron theme pack . --out theme.tar.gz`. Как всё это написать и как перенести тему с версии 0.2 - гайд «Своя тема»: `heron docs theme-author`.
