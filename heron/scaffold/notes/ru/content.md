# content — тексты страниц

Одна страница — один файл markdown. Адрес страницы задаётся путём файла,
а тип наследуется от папки: `content/uk/services/consulting.md` становится
`/services/consulting/` и получает тип, объявленный в `_index.md` раздела.

## Сюда

- страницы в markdown, по языковым папкам: `content/<язык>/…`;
- `_index.md` раздела — его заголовок, вступление и тип дочерних страниц;
- фронтматтер страницы: заголовок, описание, связи, объявленные файлы.

## Не сюда

- **Файлы изображений и видео.** Их дом — `media/`, а в тексте страницы
  остаётся только объявление: `image: media/foto/portrait.jpg`.
- **Сквозные справочники** — расписание, цены, реквизиты, которые нужны
  многим страницам сразу. Их дом — `data/`.
- **Строки интерфейса** — «Записаться», «Читать дальше». Это тема:
  `theme/i18n/<язык>.yaml`.
