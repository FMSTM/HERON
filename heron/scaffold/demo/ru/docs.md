Документация HERON лежит в репозитории движка и в самом образе — ровно той версии, которой собирается ваш сайт.

## Где читать {#where}

- **В репозитории.** [Гайды по порядку](https://github.com/FMSTM/HERON/tree/beta/docs/guide): понятия, первый сайт, страницы, тема, SEO, выкладка.
- **Для ИИ-агентов.** [AGENTS.md](https://github.com/FMSTM/HERON/blob/beta/AGENTS.md): роли, правила и карта документации.
- **В терминале.** Без интернета, той же версии, что и движок:

  ```bash
  heron docs && heron docs first-site
  ```

## Главные команды {#commands}

Команда | Что делает
`heron setup .` | конфигуратор: название, домены, о ком сайт, публикация, тема
`heron serve .` | просмотр на `localhost:8000` с пересборкой при сохранении
`heron check .` | проверка без сборки: что поправить
`heron build . --env prod --strict` | итоговая сборка в папку `dist/`
`heron page page about .` | новая страница с готовой шапкой
