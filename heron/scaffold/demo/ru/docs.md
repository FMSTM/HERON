Главные команды HERON и где читать подробнее. Документация лежит в репозитории движка и в самом образе - ровно той версии, которой собирается ваш сайт.

## Как запускать команды {#run}

Все команды ниже начинаются с `heron` - так они выглядят, если движок поставлен без Docker. В Docker вместо `heron` пишут полную команду (`-it` - тем, кто задаёт вопросы, `-p` - просмотру, конфигуратору и студии), например:

```bash
docker run --rm -it -p 127.0.0.1:8000:8000 -v "$PWD:/site" -w /site --user "$(id -u):$(id -g)" ghcr.io/fmstm/heron:prod serve .
```

## Главные команды {#commands}

1. **Создать сайт.** Задаст несколько вопросов и создаст папку сайта:

   ```bash
   heron new my-site
   ```

2. **Настроить.** Конфигуратор в браузере - откройте адрес, который напечатает движок, вместе с ключом после `#`: название, домены, о ком сайт, публикация, тема. Запускается из папки сайта:

   ```bash
   cd my-site && heron setup .
   ```

3. **Смотреть.** Сайт на `localhost:8000` пересобирается при каждом сохранении файла:

   ```bash
   heron serve .
   ```

4. **Добавить страницу и раздел.** Страница и раздел создаются сразу на всех языках сайта. Движок спросит поля с подсказками темы: Enter оставляет значение в скобках, `?` - подробная справка. Та же команда второй раз открывает страницу на правку:

   ```bash
   heron page add about . && heron category add services .
   ```

5. **Править мышью.** Студия в браузере: дерево страниц, поля с подсказками, переводы, справка темы. Откройте адрес целиком, с ключом после `#`:

   ```bash
   heron studio .
   ```

6. **Проверить.** Что заполнить и что поправить - без сборки:

   ```bash
   heron check .
   ```

7. **Собрать для проверки.** Версия dev: закрыта от поисковиков, без счётчиков:

   ```bash
   heron build . --env dev
   ```

8. **Собрать рабочую версию.** Версия prod: открыта поисковикам, предупреждения считаются ошибками. Результат - папка `dist/`:

   ```bash
   heron build . --env prod --strict
   ```

Инструкции для AI-агента лежат в корне сайта: файл `AGENTS.md` и папка `agents/`.

## Где читать {#where}

- **В репозитории.** [Гайды по порядку](https://github.com/FMSTM/HERON/tree/prod/docs/ru/guide): понятия, первый сайт, страницы, тема, поиск, публикация, своя тема.
- **Для ИИ-агентов.** [AGENTS.md](https://github.com/FMSTM/HERON/blob/prod/AGENTS.md): роли, правила и карта документации.
- **В терминале.** Без интернета, той же версии, что и движок:

  ```bash
  heron docs
  ```
